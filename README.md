# Gary's Island 🌴🍹

A retro 80s arcade synthwave game built with Phaser 3 and TypeScript.

Play as Gary on an endless runner island adventure! Dodge the pylons, collect stars and the legendary long drink cocktail to become invincible!

## Play Online
You can play the game directly in your browser here:
👉 **[Play Gary's Island](https://borderbird.github.io/Garys-Island/)**

## Local Development
To run this project locally:

1. Clone the repository
2. Install dependencies: `npm install`
3. Start the dev server: `npm run dev`
4. Build for production: `npm run build`

## Assets
- The game uses custom 8-bit retro pixel art, featuring Gary himself.
- Includes vintage CRT monitor effects and custom synthwave audio.
